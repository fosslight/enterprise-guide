# SBOM 업로드 에러 가이드

### 공통 파일 오류

| 오류 상황 | 팝업 메시지 | 조치 |
| --- | --- | --- |
| 파일명 또는 파일 자체가 없음 | 파일명 또는 업로드된 파일이 비어 있습니다. 유효한 파일을 선택해 주세요. | 파일을 다시 선택합니다. |
| 0바이트 파일 | 업로드한 파일의 크기가 0바이트입니다. 파일 내용을 확인한 후 다시 업로드해 주세요. | 내용이 있는 파일로 다시 저장합니다. |
| 엑셀 파일이 5MB 초과 | 업로드한 파일이 허용된 크기 제한을 초과했습니다. | 빈 행과 불필요한 데이터를 삭제합니다. |
| CSV 파일이 5MB 초과 | 업로드한 파일이 허용된 크기 제한을 초과했습니다. | 빈 행과 불필요한 데이터를 삭제합니다. |
| 지원하지 않는 확장자 | 업로드된 파일은 지원하지 않는 확장자입니다. | 지원되는 확장자로 저장합니다. |
| SBOM 형식을 식별할 수 없거나 일반 변환 실패 | 업로드 파일을 변환하지 못했습니다. 파일 형식과 내용을 확인해 주세요. | SPDX 또는 CycloneDX 파일인지 확인합니다. |
| 업로드 파일 복사 실패 | 업로드 파일을 임시 위치로 복사하지 못했습니다. | 파일 접근 권한과 저장 공간을 확인합니다. |

### SPDX 오류

| 오류 상황 | 팝업 메시지 | 조치 |
| --- | --- | --- |
| SPDX 구조 오류 | SPDX 문서 형식이 올바르지 않습니다. SPDX 필수 필드와 문서 구조를 확인해 주세요. | SPDX 표준 형식으로 다시 생성합니다. |
| `spdxVersion` 누락 | SPDXVersion 필드가 없습니다. SPDXVersion 정보를 추가해 주세요. | `spdxVersion`을 추가합니다. |
| SPDX JSON 문법 오류 | SPDX JSON 문법을 분석할 수 없습니다. 괄호, 따옴표, 쉼표를 확인해 주세요. | JSON 문법을 수정합니다. |
| SPDX YAML 문법 오류 | SPDX YAML 문법을 분석할 수 없습니다. 들여쓰기와 특수문자를 확인해 주세요. | 들여쓰기와 특수문자를 수정합니다. |
| SPDX RDF/XML 오류 | SPDX RDF/XML 문법을 분석할 수 없습니다. XML 구조와 네임스페이스를 확인해 주세요. | XML 태그와 네임스페이스를 수정합니다. |
| SPDX Tag-Value 오류 | SPDX Tag-Value 문법을 분석할 수 없습니다. Tag: Value 형식과 SPDXVersion: 필드를 확인해 주세요. | `Tag: Value` 형식으로 수정합니다. |
| SPDX 패키지 누락 | SPDX 문서에 패키지 정보가 없습니다. 하나 이상의 패키지 정보를 추가해 주세요. | `packages`에 패키지를 추가합니다. |
| SPDX 변환 실패 | SPDX 파일을 FOSSLight 형식으로 변환하지 못했습니다. 지원되는 SPDX 구조인지 확인해 주세요. | SPDX 파일을 다시 생성합니다. |

### CycloneDX 오류

| 오류 상황 | 팝업 메시지 | 조치 |
| --- | --- | --- |
| CycloneDX 구조 또는 `bomFormat` 오류 | CycloneDX 문서 형식이 올바르지 않습니다. CycloneDX 표준 구조를 확인해 주세요. | `bomFormat`과 문서 구조를 확인합니다. |
| CycloneDX JSON 문법 오류 | CycloneDX JSON 문법을 분석할 수 없습니다. 괄호, 따옴표, 쉼표를 확인해 주세요. | JSON 문법을 수정합니다. |
| CycloneDX XML 문법 오류 | CycloneDX XML 문법을 분석할 수 없습니다. XML 구조와 네임스페이스를 확인해 주세요. | XML 태그와 네임스페이스를 수정합니다. |
| `bomFormat` 누락 또는 오류 | CycloneDX JSON의 bomFormat 값이 없거나 올바르지 않습니다. bomFormat을 CycloneDX로 설정해 주세요. | `"bomFormat": "CycloneDX"`를 추가합니다. |
| `components` 누락 | CycloneDX 문서에 components 정보가 없습니다. 하나 이상의 구성 요소를 추가해 주세요. | `components` 배열에 구성 요소를 추가합니다. |
| CycloneDX 변환 실패 | CycloneDX 파일을 FOSSLight 형식으로 변환하지 못했습니다. 구성 요소 구조를 확인해 주세요. | 구성 요소 구조를 확인하고 다시 생성합니다. |

### Excel 오류

| 오류 상황 | 팝업 메시지 | 조치 |
| --- | --- | --- |
| 엑셀 형식 오류 | 유효한 엑셀 파일이 아닙니다. 파일 형식을 확인해 주세요. | 엑셀에서 다시 저장합니다. |
| 암호로 보호된 엑셀 | 암호로 보호된 엑셀 파일은 업로드할 수 없습니다. | 엑셀 암호 보호를 해제합니다. |
| 손상된 엑셀 | 엑셀 파일이 손상되었습니다. 파일을 다시 저장한 후 업로드해 주세요. | 원본 데이터를 새 엑셀 파일에 저장합니다. |
| 엑셀 시트 없음 | 엑셀 파일에 워크시트가 없습니다. | 워크시트를 추가합니다. |
| 엑셀 헤더 누락 | 엑셀 파일에 필요한 헤더가 없습니다. | 필요한 헤더를 추가합니다. |
| 엑셀 헤더 중복 | 엑셀 파일에 중복된 헤더가 있습니다. | 헤더명을 고유하게 수정합니다. |
| 엑셀 시트가 비어 있음 | 엑셀 워크시트가 비어 있습니다. | OSS 데이터를 추가합니다. |
| 엑셀 필수 열 누락 | 엑셀 파일에 필요한 열이 없습니다. | 필요한 열을 추가합니다. |

### CSV 및 시스템 오류

| 오류 상황 | 팝업 메시지 | 조치 |
| --- | --- | --- |
| CSV 구분자 오류 | CSV 파일은 TAB 구분자를 사용해야 합니다. | CSV를 TAB 구분자로 저장합니다. |
| CSV 인코딩 오류 | CSV 파일의 인코딩을 읽을 수 없습니다. UTF-8로 저장해 주세요. | UTF-8 형식으로 다시 저장합니다. |
| CSV 구분자 오류 | tab 구분자인 csv 파일을 업로드하세요. | CSV를 TAB 구분자로 저장합니다. |
| 파일 저장 실패 | 업로드 파일을 저장하지 못했습니다. | 저장 공간과 파일 권한을 확인합니다. |
| 임시 파일 생성 실패 | 파일 처리를 위한 임시 파일을 생성하지 못했습니다. | 서버 임시 경로와 저장 공간을 확인합니다. |
| 시스템 오류 | 파일 업로드 처리 중 예기치 않은 오류가 발생했습니다. | 잠시 후 다시 시도하고 계속되면 관리자에게 문의합니다. |
