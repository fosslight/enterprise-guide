# Request 확인과 관리
Request를 확인과 관리하는 방법을 설명합니다. 
<br><br>

# Request 확인
{: .left-bar-title }
FOSSLight Enterprise Jira에 로그인 후에 오른쪽 위 아이콘을 클릭하면 Request 목록을 확인할 수 있습니다. 
또한 등록한 이메일을 통해 Request 관련 활동에 대한 알림을 받을 수 있습니다

<br><br>

# Request Comment 작성
{: .left-bar-title }
Request 진행 과정에서 추가 정보 제공, 문의 또는 답변을 위해 Comment를 등록할 수 있습니다.

담당자가 요청한 추가 정보를 전달할 수 있습니다.
담당자의 답변을 확인하고 추가 의견을 등록할 수 있습니다.

첨부 파일과 함께 Comment를 등록할 수 있습니다.
등록한 Comment는 Atlassian 정책에 따라 수정하거나 삭제할 수 없습니다.
Comment 수정 또는 삭제가 필요한 경우 새로운 Comment로 요청해 주시면 담당자가 확인 후 반영합니다.

## Request Status 변경
{: .left-bar-title }
Request의 현재 진행 상태를 확인하고 진행 상황에 따라 Status를 변경할 수 있습니다.
주요 Status는 다음과 같습니다.

OPEN	Request가 접수된 상태
RESOLVED	Request가 해결된 상태
IN PROGRESS	담당자가 처리 중인 상태
PENDING	사용자 확인 또는 추가 정보가 필요한 상태
CLOSED	최종 종료된 상태


다만, 일부 Status 변경은 업무 처리 절차에 따라 사용자가 직접 변경할 수 없습니다.

IN PROGRESS → RESOLVED : 담당자의 처리 결과 확인이 필요한 경우
IN PROGRESS → PENDING : 담당자가 사용자에게 추가 정보 또는 확인을 요청 하는 경우
Status 변경이 필요하지만 직접 변경할 수 없는 경우에는 Comment를 통해 요청해 주시기 바랍니다
