Request 유형과 등록하는 방법을 설명합니다.  
<br><br>

# Request 유형
{: .left-bar-title }
Request 유형은 다음과 같습니다. 
- 기술 요청 지원
  서비스 사용, 설정, 연동 등 기술 문의
- 버그 신고
  서비스 이용 중 발생한 오류 또는 문제
- 기타 문의 사항
  일반 문의
- 새로운 기능 제안
  신규 기능 또는 개선 사항 제안
- 이메일 문의
  FOSSLight Enterprise 관련 문의

이메일 문의를 제외한 모든 Request는 동일한 양식으로 작성합니다.

## Request 등록
{: .left-bar-title }
Request 등록 시 아래 사항을 입력해야 합니다. 

- Category (필수) : Request에 대상 서비스를 선택
  FOSSLight Hub, FOSSLight Scanner, 기타 서비스 중 1개 
- Summary (필수) : Request 제목
- Description (필수) : Request 상세 내용
- Attachments (선택) : Request와 관련된 첨부 파일 
- Priority (선택) : Request의 Priority (default : Medium)
- 공유 대상(필수) : 사용자의 회사를 선택하면 동일한 회사에 속한 사용자들과 Request를 공유할 수 있습니다.<br>
  사용자의 회사, 아무도 없음 중 1개(Request 공유를 위해서 사용자의 회사를 선택하는 것을 추천)  
  계정 생성 직후에는 회사 정보가 표시되지 않을 수 있습니다.<br>
  담당자가 사용자의 회사 정보를 시스템에 반영 후에는 선택 가능한 회사 목록에 표시됩니다.
